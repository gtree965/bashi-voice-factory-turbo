# 巴适声工厂 (Bashi Voice Factory)

**版本:** 3.11

一个美观的语音与文字双向转换桌面级网页应用。**文字转语音 (TTS)** 基于微软 Edge TTS 引擎，支持 **14 种语言**、50+ 神经网络声音，至多 50,000 字符长文本生成，TXT 文件上传，多格式导出，以及智能分段跟读。**语音转文字 (STT)** 搭载双引擎：**SenseVoice**（中英日韩粤多语种，242MB）+ **Parakeet TDT**（英文专用，NVIDIA出品，WER仅1.7%，661MB）。全程本地离线转写，隐私无忧。

**作者:** Alex Li (ncorecpu@gmail.com)

## ✨ 核心亮点特性

### 🎙️ 本地离线音视频转文字 (v3.1)
- **极致隐私保护**: 全程在本地电脑完成会议录音、讲座视频的文字转写。没有任何音频数据会被上传到云端，保护资料私密！
- **双引擎驱动**: **SenseVoice**（默认，中英日韩粤多语种，242MB）+ **Parakeet TDT**（英文专用，NVIDIA出品，661MB）。均基于轻量级 `sherpa-onnx` 运行时。
- **VAD 精准分段**: Silero VAD 精确检测语音边界，零重叠、零卡顿、时间戳精准。
- **实时滚屏展示**: 采用 SSE 流式传输，后台提取并转写时前端网页可一比一实时滚动显示最新识别的带时间戳字幕。支持导出为 TXT、SRT 或 VTT 格式文件，方便剪辑剪映等工具使用。

### 🌍 14 种语言全球语音扩展 (v2.16)
- **全球覆盖**: 英语、中文、日语、韩语、印地语、阿拉伯语、孟加拉语、西班牙语、葡萄牙语、法语、德语、俄语、希伯来语、希腊语 —— 包含地区变体（美/英/澳、沙特/埃及、巴西/葡萄牙等）。
- **智能示例**: 点击语言标签时，示例按钮自动切换为该语言的 demo 文本。

### 📂 文本上传与多格式导出 (v2.16)
- **拖拽上传**: 将 `.txt` 文件直接拖到输入区域，即可加载文本内容。
- **智能编码识别**: 自动检测 UTF-8、GBK/GB2312、Shift-JIS、EUC-KR、Windows-1251/1252/1253/1256 和 ISO-8859-1。
- **多格式导出**: 支持下载 **MP3、WAV、OGG、FLAC** 格式（通过 FFmpeg 转换）。
- **语速范围扩展**: 语速滑块从 ±50% 扩展至 **±200%**。

### 🛡️ 智能断网无缝续传 (v2.15)
- **抗丢包架构**: 全新升级底层请求引擎，当处于不稳定 Wi-Fi 环境时，若在长文合成途中遭遇网络波动断开连接，系统将自动拦截错误并执行“指数级退避重连”。
- **局部精准重试**: 直接针对断掉的那一小块（4000字切片）向微软重新发起请求，彻底消除老版本中“网络闪断导致几万字长文全部作废重来”的噩梦。

### 🚀 终极免安装 USB 便携版 (v2.14)
- **随身携带**: 整个应用和运行环境直接打包在文件夹内，拷贝至 U 盘即可在任何无管理员权限的 Windows 电脑上双击运行。
- **智能隔离**: 首次启动后自动在沙盒内完整装配运行所需组件，日后插拔即用，绝不污染系统环境。

### 📱 局域网一键共享与手机访问 (v2.13)
- **自动配网**: 启动脚本含 10 秒即时弹窗，允许后自动扫描并提供您电脑在当前 Wi-Fi 下的局域网 IP。
- **移动全兼容**: 手机/平板浏览器直接访问，数据完全在本地路由器穿透，极致安全（可放心忽略手机端“非私密连接”警告）。

### 📄 五万字长段落连续生成 (v2.12)
- **超高容量**: 一次性可合成多达 **50,000字符**的史诗级长文。
- **丝滑体验**: 后台流式切片转换并无缝凭借音频，配合前方网页的实时进度条，杜绝漫长等待焦虑。

我们已经为您准备了真正免安装的启动器。支持 Windows, macOS 和 Linux。

1. 下载并解压整个 `edge-tts-app` 文件夹到您想放置的位置。

## 使用方法

1. **选择播放模式：**
   - "整段播放" 用于完整文本播放
   - "跟读片段" 用于短句练习

2. **输入文本** 或使用示例按钮

3. **选择片段长度**（跟读模式）：
   - 短(12词) - 适合初学者/儿童
   - 中(15词) - 推荐默认值
   - 长(20词) - 适合中级学习者
   - 关闭 - 不分段，仅按句子边界分割

4. **选择声音**

5. **调整设置**（可选）：语速、音调、片段间停顿

6. **点击"生成跟读片段"** 开始练习！

### 使用技巧

- 每行粘贴一节效果最佳
- 应用会将换行符作为段落分隔
- 建议使用"中"片段长度

### 🎙️ 语音转文字 (STT)

1. **切换到 STT 标签页**：点击页面顶部的"语音→文字"标签。
2. **首次使用**：如果尚未下载语音识别模型，请在模型下拉框中选择模型，点击"下载"。约 244 MB 的 SenseVoice 模型将保存到本地，以后无需再次下载。
3. **上传文件**：点击上传区域或直接拖拽音视频文件（MP3、MP4、WAV、M4A、OGG、FLAC、MKV 等）。
4. **选择语言**（可选）：默认为"自动识别"。可手动选择中文、英文、日语、韩语或粤语以获得更好的准确率。
5. **点击"开始转写"**：转写过程中会显示实时进度条和滚动字幕。
6. **查看结果**：完整的转写文本会出现在结果区域。点击"全部复制"可一键复制到剪贴板。
7. **导出**：从下拉菜单选择 TXT、SRT 或 VTT 格式，点击"导出"即可下载文件。

## 💡 常见问题 (FAQ)

**Q: 如果在家中的局域网环境，两个或者三个设备同时使用跟读或者转语音功能，会不会串台？**

**A:** 体验会非常流畅，而且**完全不会互相干扰**！
1. **互相隔离 (UUID机制)**：每一波语音转换请求，系统都会在后台生成完全独立的文件名（例如 `tts_8f1a...mp3`）。因此，几台设备即使同时点击“生成语音”，系统也会分别合并、分别返回声音，绝不会“串台”。
2. **并发多线程 (Threading)**：底层服务器默认开启多线程。当平板电脑在后台花几十秒钟合成 50,000 字长文的同时，哪怕有其他手机接入点击生成短片，也能做到“插队秒出”，不会被阻塞排队。
3. **极低本能消耗**：由于实际的语音合成运算全部由微软云端超级服务器承担，本地电脑只负责请求分发与音频拼接，因此即使是一台老旧的笔记本电脑作为中枢服务 3-5 台设备也毫无压力。您可以尽情地与家人同时共享使用！
